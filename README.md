# Vintage Recipes
A vintage-inspired recipe website featuring a collection of classic dessert recipes.
The design is inspired by mid-century American cookbooks, featuring soft pastel colors, serif typography, and vintage recipe illustrations.

> This project is a practice exercise created to reinforce my understanding of HTML and CSS fundamentals.

## Features
- Multi-page recipe website
- Responsive layout for desktop and mobile devices
- Vintage-inspired visual design
- Shared stylesheet across all pages
- Semantic HTML structure
- Ordered cooking instructions and ingredient lists


## Built With
- HTML5
- CSS3
